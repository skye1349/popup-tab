# Privacy Policy

Popup Tab does not collect, store, transmit, or sell personal data.

The extension uses Chrome's `tabs` permission only to move the active tab between a normal browser window and a popup window. It uses Chrome's `storage.session` API only to remember the original window and tab index while a tab is popped out, so the tab can be restored later.

No analytics, tracking scripts, remote code, or external network requests are included.
